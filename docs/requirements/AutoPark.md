# Автопарк

## Что есть

Машина:
- гос. регистрационный знак (номер машины, у одной машины может быть 2-3 номера)
- модель
- местонахождение (№1 / №2)
- VIN (первичный ключ)
- Год выпуска
- ПФМ
- ПТС
- Свид. о регистрации
- Мощность двигателя КВТ/Л.С. (пример: 220/299 и 183/250)
- Куда относится машина (Гараж, обеспечение)
- наработка (пройдено км)

Путевой лист:
- fk_car
- дата начала
- время начала
- дата конца
- время конца

Наряд на выход техники:
- дата наряда
- список машин, разрешенных на выезд с парка

Страховка:
- номер страховки (не может быть одинаковым, заполняется пользователем)
- дата страховки
- дата окончания страховки
- fk_car

Заявка на ТО:
- номер заявки
- дата заявки
- модель и номер машины
- наработка машины
- наработка с последнего ремонта
- дата ремонта
- вид ТО (что требуется обслужить)

Акт тех. обслуживания F12:
- данные машины
- наработка машины
- макс. наработка машины по формуле
- осталось наработок (макс. - текущее)
- сгенерированный текст на основе "вид ТО" из "Заявка на ТО"

Штрафы:
- номер постановления (id)
- дата постановления
- дата нарушения
- место нарушения (опционально)
- машина
- водитель
- сумма
